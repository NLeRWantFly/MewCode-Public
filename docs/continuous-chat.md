# 对话式持续执行

普通问答仍在一轮回答后结束。明确说「一直执行」「不要停」「继续，别问我，后续一直执行」，或使用 `/goal <目标>`，才启用持续任务。历史目标不能覆盖新的无关消息。

## 收尾审核

主模型不调用工具、准备收尾时，宿主先调用独立的结束审核器。审核器读取原始目标、当前插话、近期可见对话、持久化工具结果摘要和上次审核检查点，不读取思维链。审核器无工具、不能改权限或扩大任务范围。

审核状态：

- `continue`：还有已授权且可执行的下一步，注入下一步并继续同一个 Agent 循环；不发送整轮 `done`。
- `complete`：整个原始目标已验收，必须引用实际证据；有工具执行时不能只引用助手自称完成。
- `waiting_user`：缺少必要事实或授权，保留检查点，等待用户。
- `blocked`：外部或技术条件受阻，保留检查点，不伪装完成。

审核固定为 `gpt-6-astra` / `high`，使用已配置审核 Provider 的独立客户端。不修改现有安全审核模型设置；`codex-auto-review` 仅是宿主路由标签，不作为模型 ID 发送。不可用、超时、截断、无效 JSON、伪造证据都暂停；不回退到执行模型。

## 插话与控制

持续任务运行时发送文字，宿主先排入插话再取消原执行，等待工具退出与消息链修复，再启动主模型处理插话。连续插话按顺序处理，不取消正在处理的前一条插话。处理后审核插话与原目标的关系，明确安全时才接回原任务。

明确说「暂停」「先别继续」或点停止会先锁定暂停状态并清空尚未处理的等待项；迟到的审核结果不能恢复任务。发送「继续」才能恢复。说「终止任务」或 `/goal off` 终止持续目标。单独暂停命令由宿主确认，不调用执行模型。带附件消息仍使用等待区；需要立即处理时先暂停再发送。

权限等待、必要用户输入、现有迭代/输出预算均优先于审核。Plan 模式的退出不算持续目标完成。本次自动接续最多审核 64 次；连续 3 次未增加工具证据的接续会暂停防空转。达到保护上限不标完成，用户发送继续后重置接续计数。

目标、状态、最近 40 条工具证据摘要、最近 12 条审核结果保存在会话元数据中。重载时没有活跃运行器的持续任务保持暂停，不能自行重启。前端通过 `continuation` 事件及状态快照显示审核/暂停原因。

## 验证

`tests/test_continuation.py` 覆盖结构校验、审核失败关闭、原目标保持、无进展/预算、取消竞争、模型路由和证据隔离。

`tests/test_continuation_chat.py` 使用真实 Agent 循环、聊天宿主和持久化会话，配合预设模型响应，验证阶段结束自动接续、普通问答单轮结束、实际取消/清理后插话、串行多条插话、暂停不调用执行模型。

这些测试不调用在线模型，也不重启用户正在运行的应用；在线审核可用性与真实模型的判断质量不由预设响应测试保证。

本机只读路由检查：加载正常 Provider 发现结果后，独立客户端可解析为 `gpt-6-astra` / `high`。没有发送在线审核请求，也没有更改安全审核设置。
