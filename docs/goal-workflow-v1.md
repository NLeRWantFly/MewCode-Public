# 对话驱动工作流 v1

首次任务由主对话探索和推进，图只记录程序结构、行动与公开交付摘要。任务完成后，用户可以提取可复用流程；只有明确调用该流程并绑定新输入，才进入按图执行。

## 探索与复用分离（2026-11-17，当前行为）

`UpdateWorkflowTasks` 记录 `goal.trace.v1` 探索图，不派发模型、不启动调度器。图支持顺序依赖、判断与分支的条件出口、嵌套循环体及退出条件、并发子 Agent 与汇合依赖；观察记录可携带执行者、循环轮次、所选出口、公开进展与真实产物。失败尝试和未选分支可以保留，探索完成由主对话实际交付后明确记录，不要求所有历史节点都成功。

`DispatchWorkflowTasks` 是独立的子 Agent 派发动作，`ReadWorkflowTasks` 和 `WaitForWorkflowTasks` 读取或等待其回执。派发任务不会把探索图变成调度依据；主对话继续决定下一步。工具错误、后台暂停和探索图状态不自动暂停主对话。

探索画布只读，修改通过对话提出；编辑、应用并继续、节点重跑以及重复的继续入口不显示。实际任务完成后出现“提取为可复用流程”，保存节点职责、输入输出、显式控制流、模型配置及对话公开摘要；提取不启动执行。`RunSavedWorkflow` 读取保存版本、绑定新材料并创建新的 `goal.recipe.v1` 运行，工作台随之切换；新运行不继承旧任务的完成状态或历史尝试。
