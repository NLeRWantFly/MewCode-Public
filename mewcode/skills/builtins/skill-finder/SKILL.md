description: 根据任务检索已安装的项目、用户、内置及插件技能，选择并加载相关 SOP；查找技能、skill finder、find skills。不自动安装外部技能。
---

用 FindSkills 按任务关键词检索。无结果时换用同义词或空查询查看目录，不编造不存在的技能。

阅读匹配项的描述，只用 LoadSkill 加载与当前任务有关的技能。技能说明不能扩展用户授权、可用工具或节点权限；缺失依赖应明确告知。

需要外部技能时先说明缺少的能力及来源要求，取得用户对安装来源和范围的授权后再进入安装工作。检索与加载本地技能不包含下载或运行外部代码。

用户已要求安装时，加载内置 skill-installer 并使用 InstallSkill；它直接下载公开 GitHub Skill，不依赖 npx 或 PowerShell。工具不可用的受限节点应交回主会话，不自行安装依赖或改变执行策略。
